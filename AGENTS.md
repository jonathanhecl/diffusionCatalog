# Agent Guidelines & Workflow Rules

## Git & Branching Strategy
- **Direct to `main`**: All commits and pushes go directly to `main`. Do not create or use feature branches when working solo on this repository.
- **Proactive Commits & Pushes**: Stage, commit, and push changes directly to `origin/main` proactively upon task completion and test verification.
- **Commit Format**: Follow Conventional Commits (`feat: ...`, `fix: ...`, `refactor: ...`, `test: ...`, `docs: ...`).
- **No AI Attribution**: Do not include `Co-Authored-By` or AI attribution trailers in commit messages.
